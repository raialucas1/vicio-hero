VICIO.HERO

Um web app gamificado que transforma a luta contra habitos nocivos em uma jornada de progresso, boss battles, conquistas e diario pessoal.

Acessar app online Ver repositorio

Objetivo

Apoiar usuarios que desejam reduzir ou abandonar um vicio por meio de acompanhamento diario, reforco positivo e elementos de jogo.

Diferencial

O projeto troca uma tela fria de controle por uma experiencia com narrativa: o vicio vira um boss, e cada dia limpo vira progresso.

Funcionalidades

Jornada personalizada

O usuario escolhe o vicio e o boss que deseja enfrentar.

Progresso gamificado

Dias limpos geram XP, niveis, patentes e dano no boss.

Conquistas

Marcos como primeiro dia, uma semana e um mes sao registrados.

Diario pessoal

Motivacoes e reflexoes ficam salvas no navegador do usuario.

Tecnologias

  • HTML5, CSS3 e JavaScript
  • Armazenamento local com localStorage
  • Publicacao estatica via GitHub Pages
  • Servidor Node.js/Express opcional para execucao local
